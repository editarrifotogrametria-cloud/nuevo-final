## 🚀 Cómo Usar

### 1. Verificar Sistema
```bash
python3 verify_system.py
```

### 2. Instalar (Raspberry Pi Zero 2W)
```bash
chmod +x install.sh
sudo ./install.sh
sudo reboot
```

### 3. Iniciar
```bash
python3 quick_start.py
```

### 4. Acceder
Abre tu navegador en: **http://localhost:8000**
